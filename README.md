# DeskBooking
Create a web application for a company's employees to book their desk in the office.

## Requirements

To run the backend, you need to install the required packages listed in `requirements.txt`.

## Installation

1. Install the backend dependencies:
    ```sh
    cd deskbooking
    pip install -r backend/requirements.txt
    ```

2. Navigate to the `backend` directory and run the Flask application:
    ```sh
    cd backend
    python app.py
    ```

3. Install the frontend dependencies:
    ```sh
    cd ../frontend
    npm install
    ```
4. Start the frontend development server:
    ```sh
    npm run dev
    ```
